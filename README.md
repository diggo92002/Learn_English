# Speak Easy 情境英文練習

直接用瀏覽器開啟 `index.html`，即可使用單機情境英文練習頁面。提供機場、餐廳、職場三種情境，每個情境有 4 個核心單字與 100 句不同的常用範例。

- 核心單字不再固定：每個情境有 3 組本機單字，可按「換一組」。開啟頁面時會輪換本機單字；若已有網路更新的單字，會先顯示已儲存的網路單字。
- 開啟頁面或切換情境時，若網路單字超過 7 天未更新，會嘗試自動更新。也可按「網路更新」立即嘗試。頁面關閉期間不會在背景更新。
- 網路更新透過 [Datamuse API](https://www.datamuse.com/api/) 找出與情境相關、並出現在範例句裡的英文單字，透過 [MyMemory API](https://mymemory.translated.net/doc/spec.php) 取得繁體中文翻譯。外部服務若無法使用，會保留目前的單字；已記錄的生字仍會儲存在本機。
- 網路翻譯可能有歧義，請搭配例句理解。Datamuse 官方公告自 2027 年 1 月 1 日起 API 呼叫需要金鑰；屆時若未設定新的字詞來源，頁面仍可使用本機輪換單字，但無法取得新的網路單字。
- 點單字的音符，或點英文句子，即可聽發音。
- 每次顯示 10 句，可切換上一組、下一組或隨機練習；重新開啟時會從下一組開始。
- 點「查看中文」顯示翻譯。
- 點 `＋` 記錄不會的單字；在生字本點「我會了」取消紀錄。資料儲存在本機瀏覽器的 `localStorage`。
- 小測驗提供選擇與拼寫題，優先從生字本出題。
- 點「練習發音」開啟麥克風，以瀏覽器語音辨識結果和原句比較。相近度只反映辨識文字，無法精確判斷每個音。此功能需要支援 Web Speech API 的瀏覽器與麥克風權限；部分瀏覽器的語音辨識可能需要網路服務。

語音播放使用瀏覽器內建語音合成。字體可載入 Google Fonts；離線時會自動使用系統字體。

網站圖示為 `icon.svg`，已在 `index.html` 設為瀏覽器分頁圖示；上傳至 GitHub Pages 時也會使用此圖示。
